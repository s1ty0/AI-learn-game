# AI 算法学习游戏

持续维护 AI 与大模型算法知识地图，通过游戏任务和个人动态图谱，减少学习者搜索与拼接资料的时间。

当前阶段：“迷雾群岛”已有信息之海、表征工坊、学习山谷、生成港湾、积木高塔、优化营地、解码航线七章：22个主线点、7个可选支线、87个小机关与可控配乐。首屏按进度只露出当前入口；内容与评价仍为草稿。

源码仓库：[s1ty0/AI-learn-game](https://github.com/s1ty0/AI-learn-game)，默认分支`main`。数据库、凭据、依赖和个人运行记录不进入仓库。

采用[React/Next.js + React Flow + FastAPI + PostgreSQL](./docs/technical-decisions.md)。Web、API、真实PostgreSQL及迁移已接通，JS/Python依赖已锁定。详见[启动说明与实现边界](./docs/local-development.md)。

## 运行本地原型

当前电脑所需依赖已下载。在项目目录运行：

```powershell
pnpm dev
```

启动成功后打开 <http://127.0.0.1:3000>。按 `Ctrl+C` 停止服务，运行数据保存在忽略版本控制的 `.runtime/`。受限执行环境中启动PostgreSQL可能需要允许该命令在沙箱外运行。

默认进入探索世界：拨动信号、打开光闸、解开机关，完成后才认识“因果掩码”。每通过一步保存进度，刷新后可以继续；已发现的小岛可重游。详见[游玩体验规则](./docs/game-experience.md)。

方向键/WASD移动光灵；点击地面前往，点击中央光源自动靠近，或靠近后按E/空格点亮。进入机关后可直接拖动第三座灯塔，也可用方向键调信号、空格切换光闸、Enter继续。存档未连接时仍可试机关，只有成功保存后才记录通过。

回声小岛完成后开放“分光台”：调节三束信息的相对偏好，理解Softmax与加权汇聚。页眉可开启背景音乐《雾海微光》，首次默认关闭；[音乐说明](./docs/music.md)记录音轨与来源。

接着进入寻光镜，发现查询与键如何产生分数；之后可选双镜湾理解多个视角，或沿主线进入归航灯塔组合完整光路。“更多→这一程的航图”支持渐进揭示、续玩和重游；完成四个主线点即本章连通，支线另记全探索。详见[信息之海地图](./docs/information-sea-map.md)。熟练度与刷题后置，尚未实现。

归航后继续表征、训练与生成：拆分文本和向量查表、添加位置、调预测线与步长、观察发散、比较L2权衡、调概率并逐步生成、复用历史K/V。之后进入积木高塔，接通残差支路、校准LayerNorm、拼装Pre-LN块，并可选练习链式求导。“更多→群岛总览”展开已经开放的局部路线；“我的发现”保留新旧章节的发现与阶段足迹。详细范围、公式与边界见[多章光路](./docs/light-expedition.md)。

高塔之后进入“优化营地”：手选批次比较SGD方向、回放动量与Adam的历史状态、裁剪梯度范数。接着沿“解码航线”筛选Top-k/Top-p候选、比较两组固定观测点、设置EOS与新增token上限。两章包含24个新机关，均有服务端验算、阶段存档和机制档案；梯度回放、固定点演示与真实训练/随机试验明确区分。

[多Agent价值与接口计划](./docs/agent-system.md)已纳入PLAN：检索、线索、陪练、独立验证、图谱与路线分别负责，界面仍只按需出现一个向导。当前未接入模型服务。

“更多→图谱手记”保留原有知识整理界面，也可直接访问 <http://127.0.0.1:3000/workbench>。这里可以搜索160个候选知识条目、编辑个人局部地图、保存解释、查看/恢复历史，以及使用完整数值实验。恢复历史会创建新版本。浏览器草稿自动暂存，提交到数据库需点击保存。

尚未实现约10关诊断、自适应选题与跳级、AI辅导、多用户账号、完整课程或正式掌握认证。入口实验是工程验证样本，不是所有初学者的固定起点。

新增[Transformer贯穿专题](./knowledge/zh-CN/transformer/README.md)：图解、4篇模块说明、可运行教学模型与任务草案。运行 `python examples/tiny_transformer.py` 可查看合成序列上的训练与生成流程，需要PyTorch。

## 先看中文版

[打开中文知识库](./knowledge/zh-CN/README.md)。已有8张摘要入口与8份深入档案，覆盖损失函数、梯度、梯度下降、L2 正则化、Transformer、token、缩放点积注意力和交叉熵。另提供可运行的标准库数值实验：`python examples/learning_lab.py`。

Transformer（一类以注意力机制为核心的神经网络架构）等常用英文名称保留英文，首次出现附简明中文解释。知识卡不要求按编号通读，术语与知识地图持续增补。

目前内容是有来源关联的教学草稿，未经过独立审校、正式判分验证或真实试学。玩法仍为候选设计。
