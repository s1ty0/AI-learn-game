# 梯度下降深入档案

状态：分层教学草稿；可运行合成实验，待独立审校与试学。

## 1. 问题与直觉

任务是找到较小目标值对应的参数。梯度下降从当前位置反复更新；它依赖局部信息，和一次算出全局解不同。

用\(J(w)=(w-3)^2\)观察步长：更新很小可能慢，适中可能靠近目标，太大可能来回振荡或发散。不能只把游戏做成“永远往下走就会赢”，应允许玩家观察失败条件。

## 2. 定义与符号

设\(J:\mathbb R^d\to\mathbb R\)是可微标量目标，参数\(\theta\)有d个分量，第t步更新为：

\[
\theta_{t+1}=\theta_t-\eta_t\nabla J(\theta_t),\qquad\eta_t>0.
\]

\(\eta_t\)是学习率；总位移还受梯度大小影响。无约束问题采用此基本形式；有约束问题需要额外处理，不能直接沿此公式越出可行域。

## 3. 推导与机制

对上述二次函数，令误差\(e_t=w_t-3\)，固定学习率\(\eta\)，则：

\[
e_{t+1}=(1-2\eta)e_t.
\]

对非最优初值，收敛要求\(|1-2\eta|<1\)，即\(0<\eta<1\)。\(\eta=1/2\)一步到达3；\(\eta=1\)幅度不减地振荡；\(\eta>1\)误差幅度放大。这是该目标的结论，不是所有损失的通用学习率范围。

更一般的可检验条件：若梯度满足L光滑，即\(\|\nabla J(x)-\nabla J(y)\|\le L\|x-y\|\)，则：

\[
J(\theta-\eta g)\le J(\theta)-\eta(1-L\eta/2)\|g\|^2,
\quad g=\nabla J(\theta).
\]

L是梯度变化的上界常数。非零g且\(0<\eta<2/L\)时右侧严格小于当前目标。目标下降不等于到达全局最优；后者还需要凸性等额外条件和相应分析。

## 4. 实现与实验

项目实验固定同一个目标、初值和步数，比较多种学习率，保留每步参数与目标。这样可以核查改动是否真的来自步长，而非同时改变数据或初值。

一次全批次梯度通常需要遍历训练数据；成本取决于模型、样本数与反向计算，不能给所有模型一个固定复杂度。

停止条件可以结合预算、目标变化、梯度大小和验证表现。训练更久未必改善泛化，验证数据与最终测试的使用范围要分清。

## 5. 对比与变体

| 方法 | 更新依据 | 与基础梯度下降的差别 |
| --- | --- | --- |
| 全批次 | 整个训练目标的梯度 | 单步较稳定，但单步数据成本可能高 |
| 单样本/小批量SGD（随机梯度方法） | 抽样数据构造的梯度估计 | 有采样噪声，轨迹不要求每步下降 |
| Momentum（动量更新） | 结合历史方向 | 需解释状态、衰减系数和振荡 |
| Adam（自适应矩估计优化器） | 跟踪梯度的一阶、二阶统计 | 更新不等同于单一标量步长乘当前梯度 |
| 线搜索或二阶方法 | 额外探测或利用曲率 | 单步代价、假设和约束不同 |

不能把SGD的任一步损失上升都判为实现错误。比较优化器需要公平的调参预算和相同评价标准。

## 6. 边界与排错

| 现象 | 优先检查 |
| --- | --- |
| 发散或非有限值 | 学习率、数据尺度、损失实现、数值范围 |
| 长期进展慢 | 曲率尺度差异、学习率、梯度链路与模型能力 |
| 梯度零但结果差 | 驻点、饱和、不可微约定或计算图断开 |
| 训练好但验证差 | 泛化、划分与分布差异，不只更换优化器 |

每次实验优先只改变一个因素。没有证据时保留多个待查原因。

## 7. 图谱与迁移

损失定义目标，链式法则产生梯度，优化器更新参数；特征缩放改变几何尺度，正则改变目标，训练/验证划分支撑选型。理解这些关系后，再接学习率调度、预热、梯度裁剪与自适应方法。

## 8. 任务与评价

- 机制：从更新式推导误差递推，解释上述收敛区间。
- 实现：预先写出三种学习率的轨迹预期，再运行验证。
- 迁移：换成\(J(w)=5(w-3)^2\)，重新求步长条件，不能照搬\(0<\eta<1\)。
- 排错：若同时看到训练和验证异常，提出最少的下一次实验，并说明能排除什么原因。
