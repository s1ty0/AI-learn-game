# 交叉熵损失深入档案

状态：分层教学草稿；含稳定数值计算与梯度检查，待独立审校。

## 1. 问题与直觉

分类器除了猜哪一类，还需要给各类分配概率。交叉熵考察整个目标分布与预测概率，不能只看预测类别是否正确。

预测正确且给真实类0.51，与给真实类0.99，准确率相同但该样本交叉熵不同。过分自信地猜错会受到较大惩罚；这不是概率一定校准的保证。

## 2. 定义与符号

设K个互斥类别，目标分布为\(q_1,\ldots,q_K\)，预测概率为\(p_1,\ldots,p_K\)，各自非负且和为1：

\[
H(q,p)=-\sum_{k=1}^Kq_k\log p_k.
\]

log为自然对数；若目标为单一类别y，其独热表示只有\(q_y=1\)，得到\(\ell=-\log p_y\)。存在\(q_k>0,p_k=0\)时损失发散；数值实现要处理对应情况。

## 3. 推导与机制

logits（尚未转换为类别概率的输出分数）记为z。Softmax（将分数转为归一化概率的函数）定义\(p_k=e^{z_k}/\sum_je^{z_j}\)。代入可得：

\[
\ell=\log\sum_je^{z_j}-\sum_kq_kz_k.
\]

当q固定且为有效概率分布时，\(\partial\ell/\partial z_k=p_k-q_k\)。这说明梯度不仅是一个“损失数字”，还指出各类别分数的调整方向。

原创样本：\(z=[0,\ln3]\)，真实类别为第二类。概率为\([1/4,3/4]\)，损失\(-\log(3/4)\approx0.287682\)，对两个分数的梯度为\([1/4,-1/4]\)。

## 4. 实现与实验

用最大值m稳定计算\(\log\sum e^{z_j}=m+\log\sum e^{z_j-m}\)。本项目实验将所有logits同时加1000，验证概率与损失保持不变，且不直接计算\(e^{1000}\)。

PyTorch的`CrossEntropyLoss`接收模型logits；目标可以按接口约定使用类别编号或概率目标。模型输入是logits，不等于目标也必须是logits。明确类别维度、忽略编号、权重与聚合方式，见[官方说明](https://docs.pytorch.org/docs/2.15/generated/torch.nn.CrossEntropyLoss.html)。

## 5. 对比与变体

| 情境 | 应明确的选择 |
| --- | --- |
| 单标签互斥分类 | Softmax与类别目标的交叉熵 |
| 多标签分类 | 常按各标签独立建模；不能直接套互斥类别假设 |
| 软目标 | 使用完整目标分布，而非只取最大类别 |
| 标签平滑 | 改变目标分布，明确平滑约定 |
| 类别加权 | 改变各样本/类别贡献，核对均值分母 |
| 语言模型 | 对有效位置的下一token目标聚合，处理掩码与错位 |

与KL散度的联系：在有效分布和有限项条件下，\(H(q,p)=H(q)+D_{KL}(q\|p)\)。对固定q优化p时，目标中的\(H(q)\)不变；q也参与优化或分布条件改变时不能照搬这个结论。

## 6. 边界与排错

- 把概率再次作为logits传入，会产生不同的归一化与目标。
- 补齐位置未忽略，会让无意义位置影响训练。
- 批次间有效长度不同，求和与按有效位置均值会带来不同权重。
- 数值稳定不等于模型校准；需要单独的评价。

## 7. 图谱与迁移

连接概率、似然、熵、KL散度、Softmax、logits、梯度、token和数据掩码。理解后才能区分“能算分类损失”和“能正确训练语言模型”。

## 8. 任务与评价

计算原创样本的概率、损失与梯度；验证整体平移不变；将单一目标改为软分布重新推导；解释多标签任务为何不能直接按互斥类别处理。关键错误单独记录，不因背出公式而通过。
