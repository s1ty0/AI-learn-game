# 梯度深入档案

状态：分层教学草稿；待独立审校与试学。

## 1. 问题与直觉

梯度回答的是局部变化问题，不直接给出远处最优点。考虑 \(J(a,b)=(a-2)^2+3(b+1)^2\)。两个参数的同样增量可能产生不同影响，单看目标值无法决定各参数怎么改。

## 2. 定义与符号

\[
\nabla J(a,b)=\left(2(a-2),6(b+1)\right).
\]

a、b是实参数，J是标量目标，\(\nabla J\)是偏导组成的向量。在 \((0,0)\) 处梯度为 \((-4,6)\)。方向v的局部变化率为 \(\nabla J^\top v\)；上标\(\top\)表示转置。在欧氏长度约束下，非零梯度的反方向给出最陡的局部下降。

## 3. 推导与机制

对小位移\(\Delta\)，可微性给出一阶展开：

\[
J(\theta+\Delta)=J(\theta)+\nabla J(\theta)^\top\Delta+o(\|\Delta\|).
\]

\(o(\|\Delta\|)\)表示相对位移长度更快趋零的余项，不能在大位移时忽略。

若\(\Delta=-\eta\nabla J\)，一阶项为\(-\eta\|\nabla J\|^2\)。非零梯度与足够小的正步长提供下降直觉；大步长仍需考虑高阶变化。

计算链式法则样本：\(u=2w+1\)，\(J=(u-3)^2\)。于是\(dJ/dw=2(u-3)\times2\)。在w=0时，导数为-8。反向传播利用这种依赖结构累计导数，既不是目标函数，也不是参数更新算法。

## 4. 实现与实验

中心差分可检查导数：

\[
\frac{\partial J}{\partial\theta_j}\approx
\frac{J(\theta+\epsilon e_j)-J(\theta-\epsilon e_j)}{2\epsilon}.
\]

\(e_j\)是第j个坐标的单位向量，\(\epsilon\)是小正数。过大时近似误差大，过小时浮点相消可能明显；它是数值检查工具，不能当作一般神经网络训练的高效替代。

本项目实验比较手算梯度和中心差分；检查的是平滑的二次函数，不据此证明所有实现的导数正确。

## 5. 对比与变体

| 对象 | 回答的问题 |
| --- | --- |
| 导数、偏导 | 一个变量或坐标怎样影响输出？ |
| 梯度 | 标量目标对多个输入如何局部变化？ |
| Jacobian（向量输出对输入的导数矩阵） | 多个输出分别怎样变化？ |
| Hessian（标量目标的二阶偏导矩阵） | 局部曲率怎样变化？ |
| 自动微分、反向传播 | 怎样按计算依赖高效求导？ |
| 梯度下降 | 求得梯度后怎样更新参数？ |

表中后续实体需要独立展开，不能把名词表当掌握证据。

## 6. 边界与排错

零梯度不一定是极小值。\(J(w)=w^3\) 在0处导数为零但不是局部极小值；\(a^2-b^2\) 在原点也是零梯度，却有下降方向。

不可微点不能无条件使用普通梯度公式。梯度消失、梯度爆炸与图依赖断开也要分开诊断：它们可能表现类似，但原因不同。

## 7. 图谱与迁移

梯度连接目标、链式法则、反向传播、更新方法、曲率与数值检查。将“怎样求导”和“用导数怎样改参数”设为两条关系，后续优化器比较才不会混淆。

## 8. 任务与评价

按缺口选任务：计算上述梯度；判断一个方向使目标初步上升还是下降；用差分检查错误的手算导数；举出“梯度为零但不是最小值”的反例。评价既检查符号，也检查适用条件。
