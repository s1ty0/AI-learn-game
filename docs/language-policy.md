# 中文版与术语规则

日期：2026-11-07。用户已确认的语言偏好，适用于后续知识内容和产品界面。

## 1. 中文讲清楚，保留常用英文名称

正文、提示、反馈和任务说明优先中文。Transformer 等惯用名称直接保留英文，不为统一中文而强行改名。首次出现时紧跟一句简明中文解释，例如：

> Transformer（一类以注意力机制为核心的神经网络架构）。

> token（文本被切分后用于模型处理的基本单位，不固定等于一个字或一个词）。

解释针对当前场景，避免用更多陌生术语解释一个新术语。再次出现可直接使用名称；玩家能按需查看定义和对应图谱节点。

## 2. 首次出现按独立入口判断

每张可直接打开的知识卡、关卡或独立讲解段落都处理自己的首次出现。玩家可能从任意节点进入，不能假定已读过全书第一章。

界面可以展示简短说明并链接详细卡片，不必每次展开整份档案。术语说明不等于要求先完成该节点所有任务。

## 3. 显示名与稳定身份分开

- 稳定 ID 关联实体、资料、图谱与学习证据。
- 中文版显示名可以是英文，例如 Transformer、token、LoRA。
- 中文含义、英文全称和别名分别记录，便于不同关键词检索。
- 术语定义改进不创建重复节点；实质不同的算法变体应保留独立身份。
- 词表不冻结覆盖范围。遇到 token 等缺漏即可登记，再补来源、联系与任务。

本轮先完成中文版，不同步制作英文课程。原始论文标题、API（程序调用接口）名称、代码和公式保持准确。

## 4. 内容成熟度

中文草稿、来源核对、正式审校、可玩与掌握状态分别记录。为可读性写出的原创例子仍须检查数学和边界；不能因语言流畅而视为已验证。
