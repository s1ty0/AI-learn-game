# Transformer专题内容树与建设顺序

日期：2026-11-07。状态：参考成熟知识站后的专题规划；不是已完成关卡清单。

本轮已交付[贯穿专题](../knowledge/zh-CN/transformer/README.md)：自制SVG/PNG图、4篇模块文档、一层因果教学模型、8个练习与3个独立挑战草案。仍无游戏界面或学习者试学。

Transformer（一类以注意力机制为核心的神经网络架构）专题承担端到端串联任务，算法子节点承担深入解释。玩家可以目标直达，不必按下列目录机械通读。

## 1. 总览要串起什么

解释一段文本怎样成为输入表示，怎样通过模块计算，怎样得到输出分数，怎样形成训练损失与参数更新，以及推理时怎样逐步生成。分别标记训练、验证和推理情境，不能混成一个流程。

总览图已自制，并连接模块与结构化任务。教学模型已贯通前向、损失、反向、更新及生成；尚未实现原始完整编码器—解码器架构、真实文本学习和独立测试。

## 2. 内容树与真实缺口

| 模块 | 要能回答的问题 | 现有内容 | 仍需补充 |
| --- | --- | --- | --- |
| 动机与架构 | 为什么需要信息交互？有哪些组织方式？ | Transformer深入草稿 | 原始任务与现代目标对照图、替代架构的条件比较 |
| token与输入 | 文本、编号、向量分别是什么？ | token深入草稿、玩具合并、嵌入/位置模块与可运行查表 | 真实tokenizer固定版本样本、词表训练 |
| Q/K/V与单头 | 怎样打分、归一化、汇聚？ | 注意力深入草稿、可运行参考内核 | 投影实现、梯度走查、跨序列样本 |
| 多头与投影 | 为什么分头？怎样拼接？ | 模块文档、显式Q/K/V和拼接实现、参数量对照 | 手工反向推导、更多变体 |
| 掩码 | 哪些位置可见？哪些位置不计损失？ | 因果/填充与忽略标签检查，下一位对齐样本 | 长度混合、打包与边界变体 |
| 位置 | 没有位置信息会缺什么？不同方案改变哪里？ | 正弦位置模块说明与教学实现 | RoPE等独立推导、长度外推实验 |
| 残差、归一化 | 相加条件是什么？顺序为何重要？ | 跳接公式、LayerNorm轴与参数、Pre-Norm实现 | RMSNorm独立档案、不同结构对照与排错 |
| FFN与激活 | 逐位置计算什么？如何算参数？ | ReLU两层实现、参数量与模块文档 | 门控、SwiGLU及更广的中间维度实验 |
| 输出与损失 | logits怎样进入交叉熵？ | 输出头、下一位对齐、忽略项与有效位置聚合 | 软标签/权重、真实语言模型目标 |
| 更新与训练 | 梯度怎样得到并用于更新？ | 原有深入草稿、PyTorch自动微分与SGD完整教学循环 | 手工反向推导、完整优化器对比和训练稳定性 |
| 生成与效率 | 怎样选下一单位？历史计算怎样复用？ | 全局目录已有若干实体 | 采样、KV缓存、GQA/MQA、高效注意力独立档案 |
| 综合与评价 | 怎样确认实现、实验和解释可靠？ | 小型因果模型与结构/因果/梯度检查、独立挑战量规草案 | 独立数据评价、关卡实现、真实试学 |

“已有草稿”不等于模块完成，独立审校与学习者验证另记。现代变体及工程优化按独立实体持续扩展，不把所有内容挤进一篇长文。

## 3. 由问题生成任务

| 玩家问题 | 任务候选 | 需要的证据 |
| --- | --- | --- |
| 为什么同一输入会有Q、K、V？ | 改变一组投影，预测与比较输出 | 能区分匹配与取值职责，检查维度 |
| 为什么要屏蔽未来？ | 修改未来位置，比较有/无掩码结果 | 能解释哪些输出允许受影响 |
| 为什么输出是概率还要logits？ | 识别训练接口输入和稳定损失计算 | 能区分模型分数、概率、目标与损失 |
| 有多个头是不是重复计算？ | 对比不同投影与复制相同投影 | 能解释拼接与输出投影，不声称每头必有固定语义 |
| 损失下降说明模型学会了吗？ | 检查泄漏、目标错位、验证与训练结果 | 能设计区分原因的下一次实验 |

每个任务拆为预测、操作、解释、独立变式与图谱修订。系统根据画像选择任务粒度，不一次抛出整张问题表。

## 4. 先补哪些

1. 自制端到端数据流图，明确总览与每个子专题的职责。
2. 补多头、嵌入、位置、归一化与FFN的独立中文档案及来源。
3. 将现有注意力内核接成可检查的模块数据流，再设计完整小模型；不得称现有单头内核为完整Transformer。
4. 补训练标签、损失聚合、验证与生成流程，用失败样本检查关系是否贯通。
5. 基于真实任务与个人图谱验证玩法，再扩展现代变体及系统效率。

这个顺序只约束本专题生产，不限制其他算法领域的来源收集。
