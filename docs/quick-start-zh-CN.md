# 知行 · 迷雾群岛上手指南

适用版本为本机体验版，更新于2026-11-10。先体验、记录问题并返修，确认体验OK后再推进线上部署。

2026-11-11新增[公网体验入口](https://ai-learn-game.vercel.app)，现已开放注册。无需启动本机服务，也无需邀请码；设置用户名和12至128字符的密码即可开始。云端使用独立存档，本机旧进度保留。下文启动命令仍供本机开发使用。

## 1. 背景

面向AI初学者，把分散的算法知识串成可以探索的学习地图。玩家操作机关、观察变化，再用自己的话解释关系，逐渐形成个人知识网络。每轮围绕一个小目标展开。

## 2. 亮点

- **边玩边理解。** 拖动信号、调整权重、开关光路，实时观察结果。当前已有9章、37个探索点、111个机关。
- **逐步揭开地图。** 首屏只露当前入口，主线推进后开放新区域，可选支线用于进一步探索。
- **自己的星图。** 保存解释、关系和条件，比较历史版本，恢复旧图时生成新版本。
- **卡住时补一小步。** 入门画像提供起点建议，领航支持“太难、太简单、换个例子”，部分关系挑战带小互动补桥。
- **独立存档。** 每个账号分别保存探索、星图和作答，刷新后可继续。

当前教学内容仍在试学与审校。关卡完成会点亮探索成果，正式掌握和自适应跳级尚待后续校准，AI聊天辅导也尚未接入。

## 3. 玩法

基本循环是“找到光源 → 操作机关 → 观察变化 → 解释关系 → 保存到星图”。

| 操作 | 方法 |
| --- | --- |
| 移动光灵 | 方向键 / WASD，或点击地面 |
| 点亮入口 | 点击中央光源自动靠近，或靠近后按E / 空格 |
| 解机关 | 按画面提示拖动、拨滑杆、切换光闸或选择结果 |
| 首岛键盘操作 | 方向键调信号，空格切光闸，Enter继续 |
| 查看已走路线 | 右上角“更多”中的“这一程的航图”或“群岛总览” |
| 播放配乐 | 顶部音乐按钮主动开启，可调音量 |

第一段航程从回声小岛出发，接着探索分光台、寻光镜和归航灯塔。双镜湾是可选支线。每步成功保存后，刷新可从该位置继续。

## 4. 建议体验路线

首次体验约20—30分钟，可按自己的节奏暂停。

1. **从新账号开始。** 右下角选择“登录 / 创建账号”，再点“没有账号，创建一个”。用户名为3至40位字母、数字、下划线或短横线，密码为12至128个字符。本机模式注册无需邀请码。新账号有自己的初始进度，旧档案仍可从本机入口查看。
2. **先走第一束光。** 进入回声小岛，拖动灯塔或用键盘改变信号，观察光闸打开与关闭时的输出。按提示完成三步。
3. **再去分光台。** 调整三束信息的参与比例，观察汇聚结果。Softmax指把分数转换为非负、总和为1的权重的函数，讲解随探索出现。
4. **试一次续玩。** 保存成功后刷新页面，核对当前机关和已完成记录。右下角退出，再登录同一账号检查进度。
5. **整理自己的理解。** 打开“更多 → 我的星图”，接入已发现知识，写一句解释，连接并补上理由和条件，点“保存星图”。再打开历史版本比较变化。
6. **按需试其他入口。** “找到我的起点”是约10任务画像，“下一束光”给当前可达建议。“把关系讲通”在对应知识探索完成后开放情境作答，先写解释，提交后再看参考与复盘条目。

想从第一关体验时请创建新账号。已有旧档归属到账号的维护步骤见[账号说明](./accounts.md)。未提交文字暂存在当前浏览器和标签页，重要解释请主动保存。

## 5. 如何开启和关闭服务

这台电脑已经安装依赖。在 **PowerShell** 打开项目，逐行运行以下命令。使用3100和8100端口，避开此前占用3000和8000的其他项目。

```powershell
Set-Location 'C:\Users\tianyu\Documents\ChatGPT\Game-learnAI'
$env:LEARN_WEB_PORT = '3100'
$env:LEARN_API_PORT = '8100'
$env:LEARN_LOCAL_DATABASE = 'learnai'
pnpm dev
```

看到“LearnAI 本地预览已就绪”后，打开 **<http://127.0.0.1:3100>**。保留终端窗口。启动脚本会连接本机PostgreSQL、执行数据库升级，然后启动API与网页服务。首次启动或升级时多等一会儿，以“已就绪”为准。

体验结束后回到该终端，按 **Ctrl+C**。下次在PowerShell重新运行同一组命令即可。浏览器刷新只刷新页面，关闭终端会结束本次服务。

| 遇到的情况 | 处理方法 |
| --- | --- |
| 提示端口已有服务 | 若是自己此前开启的游戏，回原终端继续使用。否则将端口改为3101、8101，再启动并访问打印的地址 |
| 页面打不开 | 核对终端是否已显示“已就绪”，以及浏览器地址是否与打印地址一致 |
| 页面能打开，但保存报错 | 保留输入并尝试重读最新记录，记录错误文字。多窗口冲突时先比较服务器与草稿，再选择保留内容 |
| 登录失败 | 核对用户名、密码与长度。多次失败后按提示等待5分钟，再重试 |

运行数据保存在项目的 `.runtime/` 中，请保留该目录。排查时可查看 `.runtime/web.log` 和 `.runtime/api.log`，分享前先隐藏用户名及个人作答等信息。换电脑安装依赖时参考[完整开发说明](./local-development.md)。

## 6. 技术栈

| 部分 | 技术 | 负责什么 |
| --- | --- | --- |
| 网页与交互 | Next.js 16、React 19、TypeScript | 游戏界面、页面、账号入口与类型约束 |
| 知识地图 | React Flow | 拖动节点、连接关系、查看个人星图 |
| 界面与正文 | Tailwind CSS / CSS、Markdown、KaTeX | 样式、知识讲解和数学公式 |
| 后端 | Python 3.13、FastAPI、Pydantic | 接口、数据校验、关卡验算、账号与学习记录 |
| 数据存储 | PostgreSQL 18、SQLAlchemy、Alembic | 独立档案、事务、图谱历史和数据库升级 |
| 前端数据与草稿 | TanStack Query、IndexedDB | 请求状态和浏览器本机草稿 |
| 工程与检查 | pnpm、uv、pytest、Vitest、Playwright | 依赖管理、规则检查与浏览器流程验证 |

## 体验后怎样反馈

优先检查“是否知道下一步做什么、操作是否跟手、讲解是否刚好、保存与续玩是否可靠”。遇到问题可以按下面的短格式记录，附截图会更便于定位。

```text
入口或关卡：
操作步骤：
实际发生了什么：
我期望怎样：
是否能重复出现：
```

反馈后先返修并复测，确认本机体验OK后再继续部署。
