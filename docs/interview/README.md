# 知行项目面试材料

更新于2026-11-11，面向AI全栈工程师。内容依据当前仓库实现与既有验证记录编写，建议先看项目介绍，再练习重点问答，最后核对简历证据。

| 材料 | 使用方法 |
| --- | --- |
| [项目介绍与简历条目](./project-guide.md) | 先看项目介绍，再练四条亮点及30秒、2分钟口述，按演示脚本讲星图 |
| [面试问答与追问](./question-bank.md) | 先练末尾三组连续追问，再展开30题及AI接入设计 |
| [实现证据与表述口径](./resume-evidence.md) | 对照代码、测试和提交，确认自己可以解释每个简历动词与数字 |

建议分四次准备，每次30—45分钟。

1. 亲自保存一份星图并恢复旧版本，用页面讲清“草稿”“已保存”“历史”。
2. 打开两个标签页制造409冲突，阅读API的锁、版本检查和幂等分支。
3. 切换两个账号，解释数据库范围、会话Cookie与本机草稿之间的关系。
4. 练习2分钟介绍和五个追问，再讲当前容量、部署与学习评价的实际边界。

涉及个人履历的简历文件和修改说明在本机私有目录单独交付。这里保留项目技术材料，便于随源码维护。
