# 入门画像首版

日期：2026-11-08。状态：本地工程原型，原创探测草稿，尚未真实试学或校准。

## 玩家流程

“更多→找到我的起点”主动进入。原游戏首屏不加问卷，不强制已有玩家重新入门。选择开始后，每次只显示一个短情境；提交成功才进入下一步。可以请求一点线索、选择“还不知道”，或明确提前结束。

已提交回答和线索保存在数据库；刷新后从最近已确认进度继续。未提交的选择与理由仅保留在当前页面，离开或刷新不保证恢复，开始页明确说明。网络提交失败保留当前输入，同内容重试复用操作键；修订冲突需主动读最新进度，不自动重交。结束后可随时打开结果，本版不提供重置或重新探测。

## 探测与分支

共5类能力：数据理解、数学直觉、程序阅读、不确定性、评估与AI。每类2个槽位，总计10次回答；每类有入口、桥接、加深3个原创任务，任务源位于 `apps/api/app/intake_tasks.py`，共15个候选。

每类先做入口题。独立选择符合规则时，第二槽位使用加深题；不知道、选择不符合规则或使用线索时，改用桥接题。线索请求独立留痕，不算一次回答。不追踪反应时间，不用一次失误判定能力低；有待核查的结果后续需要新情境确认。

程序入口不熟悉时，桥接改成按钮操作直觉，证据标明“操作直觉”，不能冒充程序阅读验证。每次可填写理由，但当前只保存原文，不做关键词评分或模型评分。选择符合规则仍仅为初步线索，不是解释、迁移或独立掌握认证。

## 画像与建议

- 按能力分组展示实际探测证据，记录题目/选项、回答、理由、线索、任务版本、时间与规则反馈。
- 不知道记为 `unknown`，与未探测的域分别保留；选择不符记为 `needs_check`，不直接判不会。
- 有线索后选择符合规则记为 `supported_choice`；未使用线索记为 `independent_choice`。两者均不自动进入正式掌握投影。
- 前4题不足，或数据/数学有待核查项，建议从表征工坊的直观操作起步。
- 数据与数学已有一致初步线索，建议尝试学习山谷。全部10项选择均独立符合规则时，建议信息之海的注意力光路；注意力等专门先修仍需核对。

这些是开发期粗略分流规则，未校准为最佳起点。建议不改变解锁，不绕过原探索顺序；按钮返回当前探索。后续需接规则路线、局部补桥和独立验证，再实现可操作的推荐入口与跳级。首版不收集兴趣/目标，不按特定目标更换整个任务包，也不把五类探测等同于完整能力覆盖。

## 存档契约

新增 `intake_sessions` 表，通过0003迁移建立，与游戏阶段和个人图分开。当前仍为单人 `local-demo`，不是多用户身份实现。GET `/api/v1/intake` 只读，不创建或重置记录，不返回当前题正确选项及未请求的线索。POST `/api/v1/intake/actions` 处理 `answer`、`hint`、`finish`。

提交含修订号、唯一操作键和当前题ID。事务锁同时覆盖首次创建和后续更新；原样重复返回原结果，复用键但变内容、旧修订和结束后新动作均拒绝。每次保存事件、结果和版本；不修改探索、图快照或掌握状态。任务版本包含候选内容摘要，记录保留原题文本；版本变化时拒绝继续旧会话，显式迁移与重新探测留待后续，禁止无声重置。

规则版本的维护需随判定/路由更改升级。当前没有逐步回放旧版执行器，也未实现跨版本课程迁移。

## 验证

真实隔离PostgreSQL覆盖十步完成、动态加深/桥接、线索与未知、提前结束、程序/操作证据区分、三种起点建议、重复提交、首次并发、乱序和边界输入拒绝、旧图及探索保留。浏览器使用独立夹具，检查十步和刷新续接、提前结束、失败重试、409明确重读、390像素布局和断线返回。测试不推进真实玩家画像。
