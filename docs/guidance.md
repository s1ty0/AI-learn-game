# 一步领航与局部补桥

日期：2026-11-08。状态：规则首版，原创补桥草稿，未开展真实试学或校准。

## 1. 玩家入口

从“更多→下一束光”主动进入。界面只给当前可达目标、推荐原因和相关画像线索；可切换到已开放的支线。点击“进入这一步探索”会重新读取真实探索状态，再进入对应机关，不把过期建议当作解锁许可。

主线优先，支线不阻塞主线。没有未完成主线时继续推荐已开放未完成支线；全部完成时提示回群岛重游或整理星图，不凭探索状态认证掌握。未开放点不显示真实名称，也不能通过领航动作请求进入。

## 2. 三种反馈怎样处理

- **太难了**：先区分“关系还没想通”“术语看不懂”“操作不方便”。前两类使用一条直白关系和一个小例子补桥；操作困难只给操作指导，不写成概念能力低。
- **太简单**：收起讲解，提供一个短选择探测。选择符合规则只能算初步线索；不能自动跳级或解锁。已有帮助、答案曝光会保留，不能切换模式后冒充独立完成。
- **换个例子**：轮换同族的两个固定情境。只验证当前一条关系，不把换数值或重做当多个独立评价题族。

选择错误或“不知道”后，自动展开这条关系的补桥讲解，保留待核查状态。独立或支持下选择符合规则后，建议回原机关继续；不重置整章，也不发放正式掌握证据。每次反馈、线索和作答分别留痕。

## 3. 当前覆盖

| 机制 | 探索点 | 补桥目标 |
| --- | --- | --- |
| 因果读取 | 回声小岛 mask | 允许读取范围之外的值不通过该关系影响当前位置 |
| 权重汇聚 | 分光台 prism | 分别相乘后相加，区别于无权相加和等权平均 |
| 词表与查表 | token、embedding | 按固定表保留序列顺序查编号/向量，编号不是语义距离 |
| 平均平方误差 | loss | 先分别平方再平均，正负误差不能抵消 |

共4类、8个固定小情境，覆盖5个探索点。任务源为 `apps/api/app/guidance_content.py`。其他机制仍可用领航进入、记录反馈和请求操作指导；尚无专属补桥时明确报告覆盖缺口，不临时编造题目。

本轮不是全图自适应。当前路线仍以实际探索的可达顺序为底，结合本步反馈和选择结果提供局部支持。画像按相关粗略能力域说明已有线索和未知项，不据约10题或累计答对数自动绕过关键先修。正式能力证据、目标专属路线、替代先修路径、迁移验证和跳级接口仍未实现。

## 4. 数据与故障

新增 `guidance_sessions` 与0004迁移，独立保存规则版本、内容版本、目标/阶段、反馈原因、线索、选择结果和时间。GET `/api/v1/guidance` 只读；POST `/api/v1/guidance/actions` 支持 choose、feedback、hint、answer。查询只返回当前任务的题面和选项，不公开正确选项索引，线索需请求后才显示。

提交需匹配领航修订和探索阶段。事务锁覆盖首次创建和后续写入；同键同内容重试返回原结果，同键变内容和过期修订拒绝。探索位置变化后旧题不能继续提交。客户端409后保留输入，主动读取新题时把旧选择单独展示，不能误交到新题。

失败保留当前选择和相同重试键，连接失败可返回原场景；未提交选择只在当前页面保留，刷新不保证恢复。界面回看最近20条足迹，数据库保留全部原记录。本地原型最多1000条动作，达到后需保留历史再扩容，不清理旧数据解锁。仍是单人local-demo，无多用户身份隔离。

## 5. 证据边界

输出包括未知、待核查、独立选择符合规则和支持下完成，全部保持 mastery=unverified。一次选择不是关系解释或迁移证据；看到讲解、提示、先前答案以及同题复做不能制造新的独立证据。图谱、入门画像、探索阶段与既有掌握判断均不被领航写入覆盖。

## 6. 验证与下一批

隔离PostgreSQL检查只读性、锁区、主支线优先、全探索终点、困难原因、先支持后切换模式、错误/未知补桥、五个探索点的固定题、幂等、首次并发、过期任务及原探索/图保留。浏览器以独立夹具检查补桥、线索、作答、刷新回看、真实入口衔接、503重试、409隔离旧题选择和390像素布局。

新情境作答、解释原文和量规本人复盘已实现，见[验证室](./verification.md)。正式独立复核、评价者权限及验证后跳级继续开发。当前全图补桥覆盖和推荐效果需要审校与试学，不能由工程检查或选择题数量替代。
