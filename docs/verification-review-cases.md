# 解释复核样例草案

日期：2026-11-08。用途：训练和检查复核判断边界。下面均为项目原创的开发样例，不用于自动关键词评分，尚待独立审校。

复核者先看题设、原文和条件，再逐项标注满足、部分、缺失或不确定。选择检查与解释检查分开；遇到矛盾记录矛盾，不强行给出通过。本人复盘不能充当独立评价。

| 样例 | 原文片段 | 建议复核判断与理由 |
| --- | --- | --- |
| 因果读取：等价表达 | “位置2的计算只收0、1、2的输入。这三个数和计算都没动，所以单独把3改大不改变2。若改为能读3，需要重算。” | 路径、固定量和边界均有直接依据。无需出现‘因果掩码’四个字；仍应核对题设与独立性。 |
| 因果读取：关键词堆叠 | “因果掩码，固定规则，读取范围，边界。所以位置3增大时位置2一定增大十倍。” | 关键词不能抵消因果路径与预测矛盾。记录错误推断，不能按词数通过。 |
| 权重汇聚：完整计算 | “0.75乘负4得到负3，加上0.25乘8得到2，总和负1。若比例重新变化，必须用新比例计算，不能沿用本次结果。” | 计算关系与固定比例条件有依据；适用范围也被限定。不能据此认证真实注意力系统的全部行为。 |
| 权重汇聚：只写结果 | “答案是负1，权重很重要。” | 结果符合规则，关系解释仍缺失。需要说明如何相乘相加和比例变化的条件，不把选择检查冒充解释通过。 |
| 查表：映射关系 | “顺序是第2行再第0行，得到负2、1那行，再得到2、负1那行。词表重编号时需配套重排表行。编号只是地址，不能直接把编号差当语义距离。” | 接受文字描述替代数组排版。顺序、映射条件和编号边界均有原文依据。 |
| 查表：误认编号距离 | “能查到两行。编号2比编号0大，所以两词语义相差2。” | 查表步骤可能部分满足，但语义结论有明确错误。两个节点都认识不能替代关系验证。 |
| 误差：计算与评价范围 | “A先平方再平均是9，B是4，因此这组样本按MSE选B。先平均A会正负抵消成0。新数据还要独立检查，不能保证B更好。” | 计算、抵消原因与泛化边界均有依据。允许等价公式，不要求固定句式。 |
| 误差：越界泛化 | “A为9，B为4，所以B在任何新数据上都会更好。” | 给定样本计算符合规则，泛化边界不满足；不能用数值正确替代整个解释的通过。 |
| 自报独立 | “没看资料，我已经完全懂了。” | 自报不是可核查的独立证据；需要实际解释和新情境表现，当前状态保留待复核。 |
| 同题复做 | “看完参考解释后，再选一次正确答案。” | 保存为练习，不能增加新独立题族证据。原始失败记录及之后的帮助曝光均保留。 |
| 无法确定 | “我认为输出不变，但不确定是否还有其他路径。” | 允许不确定，不直接整章降级。应核对题目约束并定位具体关系缺口，不能强行按完整理解通过。 |
| 操作/表达差异 | “我知道两项相乘再相加，但输入数组写错了括号。” | 区分表达格式与概念关系；查真实推导，允许语义等价答案。不能仅凭排版或响应慢判能力低。 |

复核原文引用必须真实存在，但存在不等于充分。比如只引用“固定”二字，无法单独支持全部成立条件；需由复核者说明为何证据支持或不支持该条要求。自动化当前只检查引用真实性和字段完整性，不假装已经完成语义判断。

后续一致性检查至少包括：两位独立复核者对同一批样例的逐项判断、分歧原因、误通过与误拒绝、等价表达和矛盾答案。先保留不确定与分歧记录，再决定量规是否需要修订；不得为了提高一致率删除难例。
