# 算法地图的学习视图与桥接样本

日期：2026-11-07。状态：范围与依赖草案，不是已审核教材。

## 1. 全局覆盖

公共地图以[算法知识总图](./algorithm-atlas.md)为范围，广泛收集算法、损失、架构及相关机制。下表只是一种学习视图，不是公共图谱的收录边界，也不要求所有用户按整阶段线性解锁。

| 区域 | 核心问题 | 目标与深度 | 主要阶段成果 |
| --- | --- | --- | --- |
| S0 AI 全景与预测 | 什么问题适合交给模型？ | 区分任务、输入、输出、规则与学习；理解结果需要验证 | 小型预测实验及关系解释 |
| S1 数据与计算基础 | 如何表达和处理问题？ | 表格、变量、程序、数据质量；按任务接入向量、矩阵、概率和变化率 | 数据处理作品与基础关系图 |
| S2 机器学习 | 怎样学习并检验规律？ | 损失、训练、验证与测试、泛化、基线、指标、偏差与方差；实现基础模型 | 模型比较和错误分析 |
| S3 深度学习 | 神经网络如何表示与学习？ | 张量、网络、梯度、反向传播、优化和训练诊断；按路线补必要数学 | 小型网络及可解释训练记录 |
| S4 现代模型 | 如何处理语言、图像和生成任务？ | 表示、注意力、Transformer、生成建模、预训练与适配；分支深入 | 机制解释和受控实验 |
| S5 应用工程 | 怎样让模型成为可检验的工具？ | 检索增强、工具调用、工作流、评估、部署、成本与可靠性 | 有评估与错误记录的应用 |
| S6 研究探索 | 怎样提出并验证新主张？ | 阅读与复现、对照、消融、数据与评价设计、结果局限 | 可复查的复现或研究项目 |

扩展目录包括：计算机视觉、自然语言处理、语音、多模态、强化学习、推荐、时间序列、图学习、因果推断、概率建模、数据治理、安全与伦理。这里记录待覆盖范围，不声称已建成这些分支。

数学与编程是可按需调用的基础网络。S5 的入门应用体验可以早于 S3 的深度实现；解释内部机制、训练模型等任务仍须验证相应先修。

## 2. 主线、支线与毕业

- 主线：当前学习目标不可缺少的节点、关系与综合任务。
- 补基础支线：发现缺口时接入，完成后返回原目标。
- 深化支线：同一概念的推导、实现、边界与对比。
- 兴趣支线：通往某一领域的应用与项目。
- 阶段完成：该阶段指定关键节点、关系和应用得到验证。
- 专业路线完成：完成所选目标的必要主线与方向任务。
- 全收集：当前课程版本所有可选任务的额外成就，不作为所有人的毕业条件。

S6 是一种学习路线成果，不是知识地图的终点。公共目录持续扩展；以下小单元仅保留为桥接任务样本，不能据此缩小全局算法收录范围或预填学习者掌握记录。

## 3. 基础桥接节点与微任务样本

节点编号是初步设计，待 P1 转为正式数据规范。这里的硬性先修只用于首版目标；关系网络还包含解释、对比、应用等其他边。

| 节点 | 概念与可观察目标 | 微任务 | 硬性先修 |
| --- | --- | --- | --- |
| C001 | 样本：指出表格中的一个观测对象 | 从表格选一行并解释它代表什么 | 无 |
| C002 | 特征：指出用于预测的信息 | 在给定任务中选择输入列 | C001 |
| C003 | 目标：指出需要预测的结果 | 区分输入与需要预测的列 | C001 |
| C004 | 预测：区分预测结果与实际结果 | 用给定规则预测一个未展示答案的样本 | C002、C003 |
| C005 | 误差：用给定标准比较预测与实际 | 找出预测失败的样本；计算公式按需补充 | C004 |
| C006 | 训练数据：解释用于调整模型的数据 | 操作一个从样本拟合规律的小模型 | C004、C005 |
| C007 | 独立测试数据：解释保留未参与开发的数据的作用 | 指出哪些样本可用于最终独立测试 | C006 |
| C008 | 泛化：解释对未见样本表现的关注 | 比较训练内外结果，说明测试估计的限制 | C007 |
| C009 | 过拟合：解释一种训练好、测试差的现象 | 对照模型复杂度、训练结果和独立测试结果 | C008 |

首版综合目标 G001：给定两个模型、数据划分和结果，选择一个更有证据支持的方案，解释限制并更新关系图。硬性先修为 C009；其前置链已包含本单元其他必要节点。

测试集关系需保留条件：不能反复根据同一测试结果调整模型，再把该结果当作未受选择影响的最终估计。若任务允许反复调参，使用另设的验证数据或等价验证设计，并保留独立测试；该分支细节在 P2 审校。

深化支线候选：损失计算、概率输出、验证集、数据泄漏、分布变化、简单代码实现。不是每个“训练好、测试差”都只能归因于过拟合；任务应说明受控条件，不鼓励凭表面现象唯一归因。

## 4. 桥接样本目标覆盖草案

| 目标 | 为什么学 | 教学与练习 | 独立验证 |
| --- | --- | --- | --- |
| O01 输入与目标 | 先说清模型要做什么 | 表格选择与预测 | 换任务后重新区分输入和目标并解释 |
| O02 预测与误差 | 区分输出和正确性 | 逐样本观察与比较 | 用新样本比较结果，不依赖同一答案模板 |
| O03 训练与独立测试 | 防止把练习表现当实际能力 | 数据分组实验 | 指出泄漏或复用测试的问题 |
| O04 泛化与过拟合 | 解释为什么需要新数据检验 | 受控模型对比 | 区分有证据的解释与待查假设 |
| O05 关系与迁移 | 将孤立概念连成可用结构 | 更新局部图谱并说明连线 | 完成 G001，说明关键关系与限制 |

## 5. 同一桥接目标的三种路径

以下为设计走查，不是实际学习数据。

- 零基础：从 C001 的表格场景进入，经操作建立 C002—C005，再分步进入 C006—C009 和 G001。遇到术语不懂时换成具体例子，不一次展开整张图。
- 会编程但评估薄弱：验证 C001—C006 后压缩对应教学，围绕 C007、C008 建立关系，再挑战 C009 和 G001。写过训练代码不能自动认定评估已掌握。
- 熟悉统计但 AI 经验少：以解释和应用证据验证已知概念，重点接入模型训练与选择语境。若有关键缺口则定点补学，最终同样通过 G001。

上述路径均按实际证据选择，不由用户身份标签直接决定跳级。正式任务、答案与评分规则在 P2 建立。

## 6. 算法目标优先的路线

首批算法关系样本转向损失函数、梯度下降、L2 正则化，Transformer 等纳入全局地图。玩家从感兴趣的算法目标进入；系统向后检查先修缺口，再向前安排适合其能力的任务。

这些术语本身就需要正式实体、来源、关系和可持续维护的教学档案，不能只在阶段简介里出现。完整样本的任务、先修与量规在 P1—P2 补齐，本文件尚未完成新算法样本的正式依赖定义。
