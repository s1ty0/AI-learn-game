# 个人星图中的当前证据

日期：2026-11-09。状态：四类验证目标与星图之间的只读证据连接已实现，未实现正式掌握认证或自动跳级。

## 1. 玩家怎样使用

“我的星图”的已发现节点下方显示待补、可复验、进行中、等待或候选记录徽标。徽标概括这个知识关联的记录，不表示整颗星已掌握；同一知识存在候选和其他待补记录时，优先提醒待补，不隐藏缺口。

选择一颗星，右侧“这颗星的当前证据”可刷新、展开具体来源，查看初次/复验缺口与最早时间。可以精确回看该次作答和复核、前往对应验证目标、继续进行中的复验，或前往已到期来源的复验入口。星图跳转本身不创建题目、自动作答或推进游戏；正式开始仍由验证室服务器检查。

局部补桥在同一个面板中按需展开，每次只讲当前关联的一条关系。阅读属于学习支持；之后作答使用资料或帮助需如实标记，不因读过讲解或画出连线自动掌握。没有专属验证覆盖时明确保持未知，不判不会。

## 2. 哪些知识关联什么

| 知识实体 | 关联验证目标 | 适用范围 |
| --- | --- | --- |
| entity-0068 因果掩码 | mask 因果读取 | 读取范围与固定条件，不扩展成全模型掌握 |
| entity-0147 注意力权重 | weights 权重汇聚 | 给定权重下的参与比例与条件，不自动认证Softmax推导 |
| entity-0144 token、entity-0073 词嵌入 | lookup 查表表示 | 固定编号/向量映射；token先发现时可看补桥，需embedding探索完成才开放此验证 |
| entity-0014 均方误差 | loss 误差比较 | 给定指标/样本及泛化边界，不认证所有损失函数 |

映射是服务端维护的稳定ID白名单，不从玩家文字、标签、可编辑来处或连线拓扑猜测目标。损失函数总实体、Softmax等更广概念目前没有专属证据映射，显示覆盖待补。当前只读覆盖范围窄于公共目录，是显式限制。

自建或资料建议的连线仍是个人表达。选择连线时提供两端证据入口，说明“不会自动认证这条线”；两端已有候选不意味着这条具体命题、方向或条件正确。关系专属证据绑定与评分待后续。

## 3. 当前证据与历史图分开

徽标通过组件上下文呈现，不写入React Flow节点载荷。候选状态、缺口和复核修订不会随“保存星图”进入历史快照，也不会覆盖个人解释、节点位置、旧连线或旧来处。

旧版本画布只读回看原解释与布局；面板明确标注下方是当前证据，不代表旧版本当时已达到该状态。恢复旧图仍只复制原图为新修订，不撤销复核、复验或改变候选判断。

图谱编辑与证据读取分别处理。证据故障只提示重试，仍可编辑/保存星图。打开旧作答使用精确ID接口，超过最近10份列表的旧记录仍能访问；读取失败明确说明，不拿其他作答冒充目标记录。

## 4. 离开与返回

从星图进入验证前，未保存的星图操作先等待本标签页草稿写入。写入失败则保留在星图，提示先保存到数据库；写入成功也只表示本机暂存，不替代“保存星图”。正在保存、恢复草稿或加载时不重复导航。

验证页保留原有进行中情境，不因星图选择而丢弃它；显示定位目标但不自动开始新题。返回按钮写明“回到我的星图”，回到星图后可找回未同步草稿。浏览器清理、存储不可用或标签页身份丢失仍不能保证恢复。

精确历史作答提交本人复盘后重新读取该ID的报告；旧作答不因不在最近10条而失去更新显示。复验入口按来源ID过滤候选，不受来源分页或无关知识记录影响。来源过期仍由验证室返回409，星图不绕过修订、72小时或准入检查。

## 5. 接口与验证

- GET `/api/v1/star-evidence`：只返回已发现知识的当前映射覆盖与各状态记录数。没有未来名称、答案或量规。
- GET `/api/v1/star-evidence/{entity_id}?offset=0`：该已发现知识关联的目标、局部补桥和每页至多50条来源/复验摘要；未发现知识返回404。
- GET `/api/v1/verification/attempts/{attempt_id}`：精确返回已提交作答的报告与当前复核；未提交题或不存在ID返回404，仍不提前暴露答案/量规。
- GET `/api/v1/candidates?source_id=...`：定位指定来源，保留服务器准入与时间判断。

无新表或迁移，仍为13表。所有接口只读，导航也不写个人图；学习写入仍走原图谱/验证事务。当前仍是本机单人学习档案，不是多用户数据隔离或公开发布方案。

隔离数据库检查映射精度、未探索拒绝、只读性、当前复核变化、精确旧作答、不泄漏活动题、来源过滤及50条外历史。前端单元检查徽标优先级/未知/候选边界；浏览器用夹具检查草稿返回、连线端点、补桥和复验衔接、旧图当前证据提示、503仍可保存及精确历史失败。

下一批应将关键关系的验证目标与玩家关系表达明确绑定，提供“这条关系具体缺什么”的证据与复核入口，保留玩家原命题。正式掌握和跳级继续依赖真人试学、独立性/量规校准与可验证的先修替代规则，不能由徽标代替。
