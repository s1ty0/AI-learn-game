# 入门画像与自适应学习规则

日期：2026-11-07。状态：可执行规则草案，阈值尚未校准；尚无算法实现。

## 1. 画像记录什么

按数学直觉、程序阅读、数据理解、AI 概念及推理记录证据，不给人贴单一“初级/高级”标签。

每条证据记录：目标节点或关系、任务与题族、回答、是否独立完成、提示层级、评价依据、时间、内容版本及不确定项。兴趣、目标、使用设备和自报熟练度单独保存。

## 2. 约 10 个诊断槽位

下表是选题蓝图和原创示例，不是正式发布题库。每个槽位只选择一个适合当前证据的短任务，不要求做完一行中的全部变式。

这是一组基础入口示例，不限定全局算法范围。玩家选择损失函数、梯度下降、L2 正则化或 Transformer 等目标后，应替换相应槽位，优先探测目标所需桥梁；已有证据可用时不重复完成固定入门序列。

| 槽位 | 检查内容 | 默认示例 | 动态分支 |
| --- | --- | --- | --- |
| D01 | 识别数据对象 | 给出几行天气记录，指出一行表示什么 | 不熟悉表格则改为卡片，不直接判数学薄弱 |
| D02 | 输入与目标 | 要预测明日用电量，哪些是已知信息、哪个待预测？ | D01 有困难时先采用口头场景 |
| D03 | 数量比较 | 两个预测与实际值给出后，哪个更接近？说明理由 | 熟练时改为比较一组误差，不追加大量算术 |
| D04 | 规则推理 | 按一个清楚给出的条件规则预测结果 | 熟练时问规则可能在哪类样本失效 |
| D05 | 程序或操作理解 | 判断一段短伪代码的结果 | 不读代码者改为等价按钮操作，分别记录能力 |
| D06 | 不确定性直觉 | 10 次中对 8 次，能保证下次一定正确吗？ | 熟练时检查样本量和情境变化的影响 |
| D07 | AI 概念 | 解释按手写规则运行与根据样本调整规则的差别 | 不知道则标待验证，转入可观察例子 |
| D08 | 评估直觉 | 在练习过的题上全对，能否直接说明新题也会？ | 熟练时检查调参后复用测试结果的问题 |
| D09 | 关系理解 | 用自己的话连接“学习样本”和“新样本表现” | 依据前面最不确定的关键关系替换本题 |
| D10 | 边界确认 | 给一个小型新情境，解释下一步应怎样检查预测 | 在先前冲突证据处选等价探测，不作全域终考 |

规则：

- 目标约 10 个，允许学习者中途结束并从保守起点开始；不足部分留为未知。
- 每项允许“不知道”。已明确不会的点不连续换皮追问，转为后续教学。
- 槽位可替换但保留能力覆盖记录；代码任务改为操作题后不能声称验证了代码阅读。
- 矩阵等专门基础仅在目标或已有证据需要时探测，不要求所有人入门必考。
- 输出起点建议和待验证项，不输出未经校准的精确掌握百分比。
- 初始画像本身不授予大范围跳级；进入相应目标时仍核对关键能力证据。

## 3. 下一轮任务选择

1. 读取当前目标所需关键节点与关系，排除已取消或不适用的任务。
2. 找出影响当前目标的最小缺口；证据不足先选短探测任务。
3. 检查硬性先修；先修不足时选最接近已知边界的桥接任务。
4. 优先选择一个核心新目标，按需控制陌生术语、操作和计算的总负担。
5. 在相近候选中结合目标相关性、重复程度、复验需求与玩家反馈排序。
6. 给玩家简短推荐原因，允许返回、主动挑战或浏览其他区域。
7. 任务结束更新证据，再选择下一任务；不一次固定整条个人路线。

没有合适候选时，记录内容覆盖缺口，提供已审核的桥接材料或保留待补任务。不能无限循环同一道题，也不能临时编造已审核内容。

## 4. 调整决策表

| 观察到的情况 | 下一步 | 不据此推断什么 |
| --- | --- | --- |
| 独立解释与新情境应用均满足规则 | 压缩同类练习，推进新关系或更深任务 | 不自动推断相关领域全部掌握 |
| 答对但解释矛盾 | 用不同题族的短任务核查 | 不立即通过，也不立即判为不会 |
| 借助提示完成 | 保存支持下完成的证据，安排独立变式 | 不当作独立掌握 |
| 关键先修出现误解 | 定点桥接，再回到原任务 | 不重置整个阶段进度 |
| 术语或界面造成困难 | 换表达或操作方式，保留待验证项 | 不当作概念能力低 |
| 主动报告太简单或太难 | 结合表现调整或短探测 | 不单凭主观反馈更改掌握状态 |
| 回答慢、一次失误或短暂离开 | 保留记录，必要时澄清 | 不直接降级 |
| 已掌握内容在复验中出现缺口 | 标记待复核，安排针对性复习 | 不删除历史曾通过的证据 |

## 5. 验证与跳级

初版采用离散状态：未知、学习中、支持下完成、独立验证、待复核。状态属于某个目标及深度，不是人的总等级。

候选通过规则：核心评价项全部满足，无未解决的关键矛盾，存在相应的独立应用证据；关键关系还须能解释含义与适用条件。具体任务数量、严重错误定义与通过门槛在 P2 形成量规，在 P6—P7 校准。

跳级要求当前目标的关键先修有适用证据。完成诊断、浏览文本、图中已有连线、累计经验值均不能单独替代这些证据。

## 6. 待校准指标

- 单轮挑战感受与独立完成情况是否匹配。
- 同类过易任务连续出现、过难后未调整的次数。
- 提示后是否能在独立任务中应用。
- 误跳、重复教学、错误判定和目标放弃的具体原因。
- 初始画像与后续证据的冲突，以及系统修正是否及时。

首轮试学后再设数值阈值，不预设人人通用的“最佳正确率”。
